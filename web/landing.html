Three ways to see a plugin

Learn

A guided walkthrough in the order WordPress runs things: how the plugin boots, what it sets up, what visitors see, what admins get, which requests it answers. Every file and function explained, with a glossary for the jargon.

Map

Every file as a card, every include, hook, class and JavaScript call as a thread. Read it as a flow chart or a web, then send a signal through it and watch where a request can travel.

Run

Press Run on any function. A throwaway WordPress starts inside your browser, calls it with the values you choose, and shows what it returned, what it printed, and every hook it passed through.

How it works

  1. 1

    Bring a plugin

    Drop a .zip, or search WordPress.org and pick any version back to the first release. Pick two versions to see what changed.

  2. 2

    Read the story

    Pluginlore reads every PHP and JavaScript file and writes the walkthrough from the code itself. No AI guessing: the same plugin always gets the same explanation.

  3. 3

    Poke at it

    Click a file to see who can reach it. Send a signal through the map. Run a function as a visitor, a subscriber or an admin and compare what happens.

Your code stays on your computer

Pluginlore is a static web page. Your plugin is unzipped and read inside your browser; nothing is uploaded and there's no account.

  • Load from WordPress.org sends your search to WordPress.org and downloads the public zip straight to your browser.
  • Run loads WordPress Playground, WordPress and PHP compiled to WebAssembly, from WordPress.org's servers the first time. Like any website, they see your IP address (their privacy policy). The plugin's files still never leave your browser, and the sandbox can't reach the internet.
  • Security results are leads to check by hand, not verdicts. Pluginlore points; you confirm.
