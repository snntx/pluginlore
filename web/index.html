Before we look for security problems

These are leads, not verdicts. Pluginlore spots code patterns that often go with vulnerabilities: unescaped output, input reaching SQL/shell/eval, missing capability or nonce checks.

  • It will cry wolf sometimes. A flagged line may be perfectly safe.
  • It will miss things. A clean result does not mean the code is secure.
  • The scan only reads code. Nothing runs unless you press Run on a function, and that happens in a sandboxed WordPress inside your browser.
  • Probe commands are text for you to run against your own local test site. Only test software you're allowed to test.

You can switch this off any time. Whoever hosts this site can also switch it off for everyone.
